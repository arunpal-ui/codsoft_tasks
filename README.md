# CODSOFT Web Development Internship

This repository contains the three Level 1 tasks completed as part of the CodSoft Web Development Internship.

## Projects

### Task 1: Personal Portfolio
A responsive personal portfolio website showcasing personal information, skills, projects, and contact details.

**Technologies:** HTML, CSS, JavaScript

### Task 2: Landing Page
A modern and responsive landing page for a fictional product called NovaPods.

**Technologies:** HTML, CSS

### Task 3: Calculator
A simple calculator web application that performs basic arithmetic operations with an interactive interface.

**Technologies:** HTML, CSS, JavaScript

## How to Run

1. Download or clone this repository.
2. Open the desired task folder.
3. Open `index.html` in your browser.
4. For the calculator, keep all three files in the same folder.
